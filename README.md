# psst-landing

Посадочная страница Telegram-бота [@Psst_chat_bot](https://t.me/Psst_chat_bot) для рекламы (Яндекс Директ и др.).

- `/?p=akadem` — Академгородок (Новосибирск): Гимназия №5 и Лицей №130.
- `/?l=<метка>` — общая кнопка «Открыть в Telegram» с меткой источника.

Исходник — `landing/index.html` в основном репозитории бота; сюда публикуется копия (GitHub Pages).
